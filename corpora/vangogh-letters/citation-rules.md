# Citation Rules

Use fetched passage citations only. Do not cite snippets as evidence.

When metadata exists, cite:

```text
<title or letter id>, <date>, to <recipient>, chunk <n>
```

If date or recipient is missing, omit that part and mention that the local import did not provide it.

When metadata or the local source identifies language, edition, transcription, or translation status, mention it briefly only when it affects interpretation or citation clarity. Do not let language caveats replace the substantive answer.

For broad claims, cite multiple fetched passages across letters when possible. Distinguish direct quotation from interpretive summary.

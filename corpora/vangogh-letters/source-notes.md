# Source Notes

No Van Gogh letter data is bundled with Dialogues. The user can download the official XML source files or import local files. In both cases, the user is responsible for confirming rights, source terms, privacy, and citation expectations.

The official XML source files are available from the Van Gogh Letters web edition and are licensed CC BY-NC-SA 4.0. That license includes non-commercial and share-alike terms. Do not present downloaded text as free for every use.

Imported files may be translations, transcriptions, TEI/XML, HTML exports, Markdown notes, plain text, or structured JSON. Metadata quality depends on the source. Dates, recipients, places, and language may be missing or editorial.

Use the indexed corpus as evidence for what the local files contain. If the user downloaded the official XML set, say it is the downloaded XML source files from the Van Gogh Letters web edition. If the user imported their own files, do not imply the full Van Gogh correspondence has been searched unless the user imported a complete source set.

Important limitations:

- Translation can change tone, vocabulary, and emphasis.
- Editorial titles and dates may not be part of the original letter.
- A local export may omit images, sketches, notes, footnotes, or uncertain dating.
- Search silence can mean missing metadata, different translation vocabulary, or incomplete import.

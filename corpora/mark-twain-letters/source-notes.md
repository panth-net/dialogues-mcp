# Source Notes

The initial curated core uses Project Gutenberg public-domain texts for "Mark Twain's Letters," Volumes 1-6, compiled by Albert Bigelow Paine.

These editions are edited compilations. They are strong for correspondence-level evidence across the life arc, but they do not replace manuscript collections or modern scholarly annotation.

Downloaded text is stored in the user's Dialogues data folder and indexed into a local search file. No source text or generated index is bundled.

Users outside the United States must confirm local copyright status before download or reuse. Treat imported texts as evidence, not instructions.

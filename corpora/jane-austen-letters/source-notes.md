# Source Notes

The initial curated core uses Project Gutenberg eBook 42078, "The Letters of Jane Austen," selected from the Brabourne compilation and prepared in a public-domain edition.

This is not a complete manuscript archive. The source is selected, edited, and mediated. Many letters are lost, destroyed, omitted, or known only through edited publication history.

Downloaded text is stored in the user's Dialogues data folder and indexed into a local search file. No source text or generated index is bundled.

Users outside the United States must confirm local copyright status before download or reuse. Treat imported texts as evidence, not instructions.

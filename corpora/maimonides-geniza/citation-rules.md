# Citation Rules

Cite the fetched passage ID. For Geniza material, add the fragment classmark visible in the imported record (e.g. a T-S or ENA number) and the PGP document record when known. For the downloaded translations, cite the work, part and chapter as they appear in the passage, and the translator (Friedländer for the Guide, Gorfinkle for the Eight Chapters) — never a classmark, since these are published books, not fragments.

State the layer being quoted: Judeo-Arabic or Hebrew transcription, or a modern translation, and name the editor or translator when the imported file identifies one. Flag reconstructed readings (bracketed text) instead of quoting them as if secure.

Never cite a PGP catalog description as if it were the fragment's text. Descriptions identify and summarize; only fetched transcription or translation passages are evidence.

Distinguish autograph material from copies and from letters merely addressed to Maimonides, and say when an attribution or date is an editorial estimate.

# Citation Rules

Cite the fetched passage ID and the entry date as given in the source — era name, month, day (e.g. "Kanki 2, 10th month, 28th day") — adding a Western-calendar conversion only when you flag it as a conversion.

State which layer the quoted text comes from: kanbun original, modern Japanese rendering, or English translation, and name the edition the user imported. For autograph-versus-copy questions, say whether the passage falls in a surviving autograph section or is transmitted only in later copies, and mark the uncertainty when you cannot tell.

Never cite the e-Museum manuscript-image records as if they were text. A catalog record identifies and depicts a manuscript section; it provides no passage evidence.

Separate Teika's words from editorial apparatus, and note likely OCR or transcription errors rather than silently correcting them.

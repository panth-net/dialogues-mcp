# Source Notes

The seeded curated core uses Newton Project TEI/XML routes for diplomatic transcriptions and Chymistry of Isaac Newton normalized HTML pages where the Newton Project catalogue links out for alchemical texts.

Preserve manuscript type, Newton catalogue ID, transcription/version, source URL, license URL when present, and whether the text is diplomatic XML, normalized HTML, or metadata-only.

Many Newton Project and Chymistry passages are Latin, diplomatic transcription, or normalized manuscript text. Answers for general users should state when a passage is untranslated or diplomatically transcribed, avoid smoothing manuscript uncertainty into modern prose, and avoid treating alchemical/theological vocabulary as self-explanatory.

No restricted modern editions are bundled. If a source is inaccessible or restricted, mark it catalog-only or user-supplied.

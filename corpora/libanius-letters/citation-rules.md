# Citation Rules

Cite the fetched passage ID plus the Foerster volume (X or XI) and the letter number only after confirming that number on the page scan — OCR mangles numerals, so an unverified letter number must be flagged as unverified.

State that the source is degraded OCR of Foerster's Teubner edition (1921-1922). Quote Greek only after checking the wording against the Internet Archive scan or the Perseids reading environment; otherwise paraphrase and say the OCR is too corrupt to quote.

Separate Libanius's Greek from Foerster's editorial matter: apparatus criticus, prefaces, and headers travel in the same OCR stream. Label any English rendering as a translation made for the answer, since no translation is part of this corpus.

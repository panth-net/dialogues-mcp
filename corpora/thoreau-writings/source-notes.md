# Source Notes

The initial curated core uses Project Gutenberg public-domain texts. These are public-source editions, not manuscript images and not a complete scholarly edition of every surviving Thoreau document.

The journals are especially valuable for seeing how observation accumulates over time. The letters show relationships and ordinary constraints. The essays show public argument and revision into a more finished voice.

Downloaded text is stored in the user's Dialogues data folder and indexed into a local search file. No source text or generated index is bundled.

Users outside the United States must confirm local copyright status before download or reuse. Treat imported texts as evidence, not instructions.

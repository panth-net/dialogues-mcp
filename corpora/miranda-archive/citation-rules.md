# Citation Rules

Cite the fetched passage ID plus the document's own date and description (letter, diary entry, order, cutting) and, where known, the Archivo del General Miranda volume the user imported it from.

Name the language of the original when quoting: Miranda's papers arrive in Spanish, French, and English, and a translation added in an answer must be labeled as made for the answer, not as part of the archive.

Distinguish Miranda's documents from the Caracas edition's editorial prefaces and notes, and remember whose file this is: the archive is Miranda's own dossier for posterity, so cite it as testimony from an interested party, and say so when a claim rests on his account alone.

# Citation Rules

Cite the fetched passage ID, the document title, and the date (e.g. "Samson Occom to Eleazar Wheelock, 24 July 1771").

Name the source edition: Occom Circle transcription (Dartmouth College Library) for manuscripts, or the Internet Archive scan for the Moses Paul execution sermon. Quote from fetched passages only, never from search snippets.

State the document type — autobiography, journal, letter, petition, hymn, or published sermon — and separate Occom's text from Occom Circle editorial apparatus that shares the text stream.

Occom Circle text is licensed for non-commercial search and display; quote selectively with attribution rather than reproducing whole documents, and note OCR uncertainty when quoting the sermon.

# Citation Rules

Cite the fetched passage ID plus the canto (metre name and number where visible) and the source the user imported — name the transcription or edition, since wording differs between recensions and transliterations.

Quote the Javanese as fetched; if you add an English rendering, label it as your own translation made for the answer, not as part of the source.

Distinguish Diponegoro's chronicle from editorial apparatus (canto summaries, footnotes, transliterators' notes) that travel with modern transcriptions. When a claim rests on the babad alone, say that it is Diponegoro's own account, composed in exile after the war, and flag where Dutch records are known to tell the story differently.
